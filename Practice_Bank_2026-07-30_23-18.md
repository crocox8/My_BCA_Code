### Question 2:
1. Write a Python program that implements a stack using linked lists, providing methods for push, pop, and peek.

**Solution:**
```
class Node:
    def __init__(self, data=None):
        self.data = data
        self.next = None

class Stack:
    def __init__(self):
        self.top = None

    def push(self, data):
        node = Node(data)
        node.next = self.top
        self.top = node

    def pop(self):
        if self.top is None:
            return None
        data = self.top.data
        self.top = self.top.next
        return data

    def peek(self):
        if self.top is None:
            return None
        return self.top.data
```

### Question 3:
2. Implement a binary search algorithm in Python to find an element in a sorted array of integers.

**Solution:**
```
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```

### Question 4:
3. Create a Python program that uses loops to generate the first 50 prime numbers.

**Solution:**
```
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True

prime_numbers = []
n = 2
while len(prime_numbers) < 50:
    if is_prime(n):
        prime_numbers.append(n)
    n += 1

print(prime_numbers)
```
