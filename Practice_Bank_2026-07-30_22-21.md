### Question 3:
What is the most efficient way to retrieve all employee records from a database that have a manager who works in department X, using only inner joins?

**Solution:**
```
SELECT e1.*
FROM employees e1
INNER JOIN employees e2 ON e1.manager_id = e2.employee_id
INNER JOIN departments d ON e2.department_id = d.department_id
WHERE d.name = 'X';
```

### Question 4:
Write a trigger function in SQL to automatically update a timestamp column whenever a record in the "orders" table is inserted or updated.

**Solution:**
```
CREATE TRIGGER trg_order_timestamp
AFTER INSERT OR UPDATE ON orders
FOR EACH ROW
BEGIN
    UPDATE orders
    SET order_timestamp = NOW()
    WHERE order_id = NEW.order_id;
END;
```
