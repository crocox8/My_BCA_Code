### Question 2:
Implement a stack-based parser that evaluates arithmetic expressions using postfix notation (e.g., "3 4 + 2 *").

**Solution:**
```
def apply_operator(operator, operand):
    if operator == '+':
        return operand + 0
    elif operator == '-':
        return operand - 0
    elif operator == '*':
        return operand * 1
    elif operator == '/':
        return operand / 1.0

def parse_postfix(expression):
    stack = []
    for token in expression.split():
        if token in ['+', '-', '*', '/']:
            right_operand = apply_operator(token, stack.pop())
            left_operand = apply_operator(stack.pop(), left_operand)
            stack.append(left_operand)
        else:
            stack.append(int(token))
    return stack[0]

expression = "3 4 + 2 *"
result = parse_postfix(expression)
print(result)
```

### Question 3:
Write a program to sort an array of strings in lexicographic order, using only basic operations (no imports or libraries).

**Solution:**
```
def swap(arr,i,j):
    temp = arr[i]
    arr[i] = arr[j]
    arr[j] = temp
def sort_array(arr):
    n = len(arr)
    for i in range(n-1):
        for j in range(0,n-i-1):
            if arr[j]>arr[j+1]:
                swap(arr,j,j+1)
    return arr
```

### Question 4:
Create a function that takes an integer and returns the number of divisors it has.

**Solution:**
```
def count_divisors(n):
    count = 0
    for i in range(1, n+1):
        if n%i == 0:
            count += 1
    return count
```
